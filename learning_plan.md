# STEM Year 2026: Puzzling Phenomena
**May 26 – December 31, 2026 | ~32 weeks | ~2 hrs/day**

## Student Profile
- Age: 13.5, homeschooled
- Coding: some experience (Python basics / Scratch level — can write working simple programs)
- All four STEM domains: Math, CS, Physics/Engineering, Biology/Chemistry

## Design Philosophy
Each session opens with a question nobody handed you the answer to yet. Subjects rotate week to week — sometimes math leads, sometimes code, sometimes a jar of chemicals. Progress in each domain is real but disguised by the phenomenon framing.

Sessions are never "now we study X" — they are "here is something weird; let's figure out why."

## Progression Tracks (running beneath the surface)
- **Math:** arithmetic → number theory → geometry → combinatorics → probability → statistics → intro calculus intuition
- **CS:** variables/loops → functions → data structures → algorithms → recursion → simulation → crypto basics → ML intuition
- **Physics:** observation/measurement → forces → waves → fields → thermodynamics → taste of relativity
- **Bio/Chem:** scales of life → chemistry of matter → genetics → evolution → systems biology → biochem
